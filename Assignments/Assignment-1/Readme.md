## 📌 Assignment Objective

The goal of this assignment is to:

- Practice database design using **realistic names**
- Understand how to work with **multiple tables and data types**
- Improve your SQL skills with hands-on examples
- Be comfortable writing and reading SQL queries

---

## 🧠 What You’ll Learn

- How to structure relational databases
- How to write `CREATE`, `INSERT`, `SELECT`, and `DROP` queries
- How to use meaningful naming conventions for tables and columns
- Importance of commenting in SQL scripts

---

## 🛠️ How to Use

1. Open your MySQL or any SQL-compatible environment.
2. Run the `Assignment-1.sql` script.
3. Explore the databases using the provided queries.
4. Modify or extend the records as part of your learning.
